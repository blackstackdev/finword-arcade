# Changelog

## 0.1.0 — 2026-10-25

- First playable Finword browser arcade and responsive website.
- Growing procedural shark, original neon block maze and six ocean word challenges.
- Cruise / Arcade speeds, three lives, word bonuses, pause and fresh runs.
- Keyboard, touch buttons and swipe steering; optional original synthesized sound.
- Browser-local personal best and sound preference, with storage-disabled recovery.
- Canvas fallback for unavailable/lost WebGL contexts and reduced-motion support.
- Fixed required food disappearing when a long body temporarily divided the reef.
- Isolated static site with automated checks and GitHub Pages deployment.
